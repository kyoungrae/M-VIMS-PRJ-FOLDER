문자발송관리

문자 발송: 신규 발송 → 발송 버튼 → 단건/다중 분기. 다중 시 단계명은 사용자 조회 및 다중 선택 → 문자서비스 연계(가정) → 발송 이력 반영.
발송 이력: 일자 입력 → 정보 검색 → 문자 발송 이력 조회.

시작 → 신규 발송(Y) → 문자 발송 버튼 → 문자 다중 전송 여부 — N: 보내는 사람·받는 사람·메시지·실시간/예약 / Y: 사용자 조회 및 다중 선택 → 보내는 사람·받는 사람 목록·메시지·실시간/예약 → 문자서비스 연계 → 발송 이력 → 종료

문자 발송 프로토타입: 실제 SMS 연동 없음

사용자 조회 및 다중 선택

기존 명칭 「문자 다중 전송 시 사용자 조회」를 본 문구로 정리한 화면입니다.

선택된 수신자가 없습니다.
시작 → 일자 입력 → 정보 검색 → 문자 발송 이력 → 종료

발송 이력 조회 일자 범위로 문자 발송 이력 검색

발송일시 구분 보낸 사람 수신 메시지 요약

조건을 입력하고 검색하거나, 아직 이력이 없습니다.
